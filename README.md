# CHRONOS

CHRONOS is a bilingual (Japanese / Russian) mobile-first history learning prototype.

Core idea: understand the human world through **cause → event → consequence → modern echoes**, rather than memorising dates.

## Information architecture
- HOME: time dial from ~300,000 years ago to 2026
- TIMELINE: horizontally scrollable “human-history scroll” + synchronized world map
- EVENT: STORY / CONNECTIONS / WORLD / MEANING
- MEANING: DEEP DIVE / ECHOES / SAPIENS
- UNDERSTANDING: natural-language explanation and structured tutor feedback
- LIBRARY: clickable index
- MY MAP: learning map that clears as understanding grows

The main timeline begins with Homo sapiens. “Before humans” is available as a deeper Earth/life-history layer.
